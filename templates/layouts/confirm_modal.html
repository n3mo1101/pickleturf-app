{% comment %} Reusable confirmation modal. Two usage modes: 1. Declarative — add these attributes to a
or element: data-pt-confirm (enables interception) data-pt-confirm-title data-pt-confirm-body data-pt-confirm-label (confirm button text) data-pt-confirm-class (bootstrap button class, e.g. btn-danger) data-pt-confirm-details (JSON array of {label, value} — optional) 2. Programmatic — call window.ptConfirm({title, body, details, confirmLabel, confirmClass, onConfirm}) from JS. {% endcomment %}
